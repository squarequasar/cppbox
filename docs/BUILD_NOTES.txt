CppBox build notes

============================================================

This repository contains the v1.0.1 PowerShell sources and public distribution artifacts for both stable releases, v1.0.0 and v1.0.1.

The v1.0.1 Launcher.ps1 and Setup-CppBox.ps1 were extracted from the payload embedded in its setup executable. Their content is preserved; line endings are normalized to LF for this repository, and the UTF-8 BOM is retained for Windows PowerShell. The native C wrapper sources remain in src/launcher_src/; they are not included in the release ZIP.

The release packages are included in:

release/CppBox_v1.0.0.zip
release/CppBox_v1.0.1.zip

The v1.0.1 archive contains its setup executable, user README, and full development log.

============================================================

Important

The setup exe embeds a generated payload ZIP.

In the original local build tree, that generated payload was written into:

src/launcher_src/payload.h

That file is intentionally not included in this repository because it is generated and large.

============================================================

Main components

Launcher.ps1
Graphical user interface for CppBox.

Setup-CppBox.ps1
Downloads/extracts VS Code and WinLibs GCC, prepares the portable workspace, and opens VS Code.

CppBoxLauncher.c
Small Windows GUI executable wrapper that starts Launcher.ps1 without showing a console window.

CppBoxSetup.c
Single-file setup executable source. It extracts the embedded payload, creates the desktop shortcut, launches CppBox, and schedules setup self-delete.
