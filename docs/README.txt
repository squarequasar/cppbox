CppBox v1.0.2 — портативное окружение для C++ под Windows.

VS Code, компилятор и настройки хранятся в папке cppbox. Свои программы создавай в workspace.

Требуется Windows x64 и интернет для первоначальной установки среды. Windows на ARM не входит в список официально поддерживаемых платформ.

Для первоначальной установки оставь не менее 4 ГБ свободного места. Компоненты среды вместе с сохраненными архивами занимают около 3 ГБ. Для своих проектов и дополнительных расширений понадобится отдельное место. Размер проверен 4 октября 2026 года и может меняться при обновлении компонентов.

============================================================

Изменения в v1.0.2

Исправлена конфигурация сборки и отладки активного C++ файла через F5.
Результаты сборки остаются во внутренней папке и не засоряют workspace.
Сохранены прогресс загрузки, отмена установки и автоматическая установка C/C++ Extension Pack из v1.0.1.

============================================================

Установка

1. Скачай CppBox_Setup_v1.0.2.exe.
2. Помести его туда, где хочешь хранить CppBox, и запусти.
3. Рядом появится папка cppbox, а на рабочем столе — ярлык CppBox.
4. Установщик после распаковки удалится сам.
5. Открой CppBox и нажми Установить CppBox. Для загрузки среды нужен интернет.
6. Дождись зеленого статуса и нажми Открыть VS Code.

============================================================

Первый запуск и расширения

Когда VS Code спросит, доверяешь ли ты workspace, нажми Trust / Доверять.
Без доверия к рабочей папке сборка и отладка могут быть недоступны.

CppBox автоматически устанавливает C/C++ Extension Pack от Microsoft.
Если расширения нет, открой Extensions, найди C/C++ Extension Pack от Microsoft и установи его.

============================================================

Как писать и запускать код

Создавай .cpp файлы в workspace, например hello.cpp или test.cpp.
Открой нужный файл, сохрани его и нажми F5 для сборки и отладки.
Чтобы проверить отладку, поставь точку остановки на исполняемой строке. Повторное F5 продолжает выполнение.
Собирается активный файл, а не все .cpp файлы как один проект.

============================================================

Если что-то сломалось

Проверь доверие к workspace и наличие расширения C/C++ от Microsoft.
Кнопка Починить сбрасывает и повторно устанавливает среду. При этом удаляются настройки и расширения VS Code, компилятор и конфигурация workspace. Исходные .cpp файлы сохраняются. Перед восстановлением сделай копию своих настроек, если менял их.

Если проблема осталась, создай обращение на https://github.com/squarequasar/cppbox/issues и укажи версию CppBox, версию Windows и текст ошибки. Перед отправкой логов убери личные пути и другие приватные данные.
