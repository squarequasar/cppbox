# CppBox v1.0.1

CppBox v1.0.1 improves the setup flow and launcher.

**Tag:** `v1.0.1`

## Download

[Download CppBox v1.0.1](https://github.com/squarequasar/cppbox/releases/download/v1.0.1/CppBox_v1.0.1.zip).

## What's changed

- Shows actual download progress in megabytes and percent, and lets you cancel installation.
- Keeps the launcher responsive while setup runs.
- Lets you move the launcher window and displays the CppBox version in it.
- Automatically installs Microsoft's C/C++ Extension Pack into the portable VS Code environment.

## Install

Download and extract `CppBox_v1.0.1.zip`, then run `CppBox_Setup_v1.0.1.exe`. The setup creates a `cppbox` folder beside itself, adds a desktop shortcut, and removes itself after extraction. An internet connection is required for the first environment setup.
