# CppBox v1.0.1

CppBox v1.0.1 improves the setup flow and launcher.

## Download

[Download CppBox v1.0.1](https://github.com/squarequasar/cppbox/releases/download/v1.0.1/CppBox_Setup_v1.0.1.exe)

[Optional ZIP package](https://github.com/squarequasar/cppbox/releases/download/v1.0.1/CppBox_v1.0.1.zip) containing the setup executable, user README, and development log.

## What's Changed

- Shows actual download progress in megabytes and percent, and lets you cancel installation.
- Keeps the launcher responsive while setup runs.
- Displays the CppBox version in the launcher.
- Automatically installs Microsoft's C/C++ Extension Pack into the portable VS Code environment.

## Quick Start

1. Download and run `CppBox_Setup_v1.0.1.exe` where you want CppBox to be stored.
2. Open the CppBox desktop shortcut and install the environment through the launcher.
3. Open VS Code and trust the workspace when prompted.
4. Ensure Microsoft's C/C++ Extension Pack is installed; install it from Extensions if it is missing.
5. Save your `.cpp` files in `workspace`. Build and run the active file using the C/C++ extension's command menu.

Internet access is required during initial setup. The setup file removes itself after extracting CppBox.
