# CppBox v1.0.0

The first stable CppBox release.

## Download

[Download CppBox v1.0.0](https://github.com/squarequasar/cppbox/releases/download/v1.0.0/CppBox_Setup_v1.0.0.exe)

[Optional ZIP package](https://github.com/squarequasar/cppbox/releases/download/v1.0.0/CppBox_v1.0.0.zip) containing the same setup executable.

## What's Included

- A single-file setup executable that extracts CppBox beside itself, creates a desktop shortcut, and removes the setup file after extraction.
- A portable VS Code environment and WinLibs GCC/GDB toolchain kept inside the CppBox folder.
- A clean workspace for C++ source files, with build output kept in the internal folder.
- A graphical launcher with install, open-code-folder, and repair actions.
- CppBox branding, Windows icon, and `made by squarequasar` credit.

## Quick Start

1. Download and run `CppBox_Setup_v1.0.0.exe` where you want CppBox to be stored.
2. Open the CppBox desktop shortcut and install the environment through the launcher.
3. Open VS Code and trust the workspace when prompted.
4. Install **C/C++ Extension Pack** by Microsoft from VS Code's Extensions view.
5. Save your `.cpp` files in `workspace`. Build and run the active file using the C/C++ extension's command menu.

Internet access is required during initial setup. The setup file removes itself after extracting CppBox.
