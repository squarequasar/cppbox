# CppBox v1.0.0

The first stable CppBox release.

**Tag:** `v1.0.0`

## Downloads

- [CppBox Setup](https://github.com/squarequasar/cppbox/releases/download/v1.0.0/CppBox_Setup_v1.0.0.exe)
- [ZIP package](https://github.com/squarequasar/cppbox/releases/download/v1.0.0/CppBox_v1.0.0.zip)

## Included

- A single-file setup executable that extracts CppBox beside itself, creates a desktop shortcut, and removes the setup file after extraction.
- A portable VS Code environment and WinLibs GCC/GDB toolchain kept inside the CppBox folder.
- A clean workspace for C++ source files, with build output kept in the internal folder.
- A graphical launcher with install, open-code-folder, and repair actions.
- CppBox branding, Windows icon, and `made by squarequasar` credit.

## First launch

Trust the workspace when VS Code prompts you. The checked-in setup flow attempts to install Microsoft's C/C++ Extension Pack into the portable environment; if it is missing, install **C/C++ Extension Pack** by Microsoft from VS Code Extensions.
